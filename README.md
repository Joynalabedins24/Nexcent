# Nexcent - Responsive Landing Page

A modern and responsive landing page built with **HTML5** and **CSS3**.  
This project was created as a web design/class project and focuses on clean UI, responsive layouts, reusable sections, and a professional visual design.

## ✨ Features

- 📱 Responsive landing page layout
- 🧭 Navigation bar with Login and Sign Up buttons
- 🚀 Hero section with call-to-action
- 🤝 Client/logo showcase
- 👥 Community feature cards
- 📊 Statistics and achievement section
- 📅 Calendar/experience section
- 💬 Customer testimonial section
- 📝 Blog/news cards
- 🎯 Demo call-to-action section
- 📧 Newsletter/email subscription form
- 🔗 Social media icons using Font Awesome
- 🎨 Clean and modern color palette
- 🖱️ Hover effects and interactive UI elements

## 🛠️ Technologies Used

| Technology | Purpose |

## 🎨 Design

The project uses a simple professional color scheme:

- **Primary Green:** `#4caf4f`
- **Dark Text:** `#263238`
- **Light Background:** `#f5f7fa`
- **Secondary Text:** `#4d4d4d`

The **Inter** font is used throughout the website for a clean and modern appearance.

## 🚀 How to Run

No framework or build tool is required.

1. Clone the repository:

```bash
git clone https://github.com/Joynalabedins24/Nexcent.git
```

2. Open the project folder:

```bash
cd Nexcent
```

3. Open `index.html` in your browser.

You can also use **VS Code + Live Server** for easier development.
